# Taipei Urban Rat Lab demo video

本資料夾是 Taipei Urban Rat Lab 的可重建簡報影片工程。影片使用 Remotion 組版、Playwright 擷取本機 UI，不截正式 Firebase 資料。

## 產品決策

| 項目 | 決定 |
|---|---|
| 用途 | 黑客松評審、成果簡報與合作溝通 |
| 受眾 | 懂市政、不一定熟悉 GIS 或研究方法的臺灣觀眾 |
| 核心訊息 | 看見鼠跡不等於知道鼠群；用可解釋的空間連通模型，將線索轉為待驗證的優先調查順序 |
| 規格 | 1920×1080、30 fps、約 59 秒、繁體中文 |
| 內容 | 民眾通報／現場調查表單、鼠跡分佈與環境因子 tabs、研究文獻、鼠群移動研究、街廓連通圖、距離衰減、道路阻隔、地面／地下傳遞、優先調查指數與研究邊界 |
| 限制 | 不把通報量稱為鼠口數量；不把 L1–L5 稱為已驗證風險；模擬資料必須標示 |

## 音樂結構與斷點

- `analysis/fun-time.analysis.json` 以 Web Audio 解碼分析前 90 秒；主節拍候選為 125 BPM（自相關分數 0.5973）。
- 每拍 0.48 秒，每個 4/4 小節 1.92 秒；31 小節為 59.52 秒。
- 0–5.76 秒能量較低，用於提問與問題建立。
- 21.12–30.72 秒能量較穩定，用於研究依據與模型導入。
- 30.72–36.48 秒有明顯能量下降，用於連通圖與公式解釋，降低訊息負擔。
- 46.08 秒後音樂能量逐步上升，用於 L1–L5 結果、研究邊界與片尾。

## 鼠群移動知識口徑

- Byers et al. (2021) 在 Vancouver 分析 605 隻溝鼠，解出 1,246 組近親配對；13 組（1%）跨越不同街廓，75% 的近親捕獲距離在 33 m 內。這支持街廓尺度與城市阻隔可能重要，但不是臺北穿越機率。DOI: `10.1111/eva.13049`。
- Combs et al. (2018) 的四城市比較發現最短距離尺度有高空間自相關，且部分城市的遺傳不連續與道路等地景特徵一致；仍不能將相關直接當成因果或通行機率。DOI: `10.1098/rspb.2018.0245`。
- 影片使用「空間連通權重」「優先調查指數」，不使用「感染機率」「遷移機率」或「高鼠患區」。

## 資料與隱私

- 公開地圖使用 repository 內的固定資料。
- 政府調查、防治、採樣及基因資料目前為 `synthetic_mock`。
- 不截正式站上的帳號、姓名、描述、照片或私人精確位置。
- 官方表單透過 dev-only 測試帳號正常登入；民眾表單以只在 Vite dev 生效的 `video-preview` 顯示真實表單 UI。預覽不提供使用者身分，不能繞過 Firestore／Storage 規則，也不送出紀錄。
- 片尾固定顯示：「研究與展演用原型・非官方系統・部分資料為模擬」。

## 開發

網站先在 `http://127.0.0.1:4173` 啟動，再執行：

```bash
cd video
npm install
npm run capture
npm run capture:official
npm run dev
npm run render
npm run render:nobgm
```

`capture:official` 會使用 `apps/web/.env.local` 中 dev-only、gitignored 的市府測試帳號擷取「鼠跡調查」，並使用 dev-only `video-preview` 擷取「民眾通報」空白表單。帳密不會進入 capture 腳本、截圖或 git。

影片使用的配樂放在 `public/audio/bgm.mp3`，並納入專案版本控制，確保其他人 clone 後可直接預覽與渲染。
